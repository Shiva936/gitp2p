# Contributor Covenant Code of Conduct

## Community Values

We are committed to a welcoming, inclusive, and productive community. Participants are expected to:

- Treat others with respect and empathy
- Give and accept constructive feedback gracefully
- Focus on what is best for the community and project
- Assume good intent while addressing disagreements
- Welcome contributors of all backgrounds and experience levels

## Unacceptable Behavior

The following is not tolerated:

- Harassment, discrimination, or derogatory comments related to identity or background
- Personal attacks, trolling, or insulting/derogatory remarks
- Public or private harassment
- Publishing others' private information without permission (doxxing)
- Sexual language or imagery, or unwelcome sexual attention
- Other conduct that could reasonably be considered inappropriate in a professional setting
- Disruption of discussions, issues, or community spaces

## Reporting Process

If you experience or witness unacceptable behavior:

1. **GitHub** — Contact repository maintainers via private message or the repository's contact mechanism.
2. **Security-sensitive conduct** — Use the process in [SECURITY.md](docs/SECURITY.md) if the incident involves security.

Include:

- What happened and when
- Who was involved (usernames)
- Links or screenshots if applicable
- Whether you prefer confidential handling

Reports are taken seriously regardless of the reporter's or subject's role in the project.

## Enforcement Process

Maintainers will:

1. Acknowledge receipt of the report promptly.
2. Review the incident with discretion and fairness.
3. Consult involved parties as appropriate.
4. Determine a response consistent with this code and project interests.
5. Document the outcome for maintainers (not necessarily public).

Maintainers may remove, edit, or reject contributions and communications that violate this code.

## Consequences

Actions may include:

- **Warning** — Private notice with expected behavior change.
- **Temporary ban** — Exclusion from community spaces for a defined period.
- **Permanent ban** — Removal from all project community spaces.

Severity and recurrence influence the response. Maintainers prioritize community safety.

## Maintainer Responsibilities

Maintainers will:

- Model the standards in this document
- Apply consequences fairly and consistently
- Protect reporters from retaliation
- Revise this code of conduct when community needs evolve

Maintainers who fail to enforce this code may be removed by project leadership.

## Scope

This code applies in all community spaces: GitHub issues, pull requests, discussions, and any official project channels. It also applies when an individual represents the project in public spaces.
